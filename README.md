## Overview

Remnants scatters hundreds of handcrafted and procedurally assembled ruins, dungeons, abandoned settlements, and ancient structures throughout generated Terraria worlds. Each structure contains themed enemy encounters, lore notes, unique loot tables, and environmental storytelling that makes world exploration feel populated with history.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Remnants** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **World Structures** | Hundreds of ruins and dungeons scattered across generated worlds |
| **Themed Enemies** | Each structure type has contextually appropriate enemy encounters |
| **Unique Loot** | Structure-specific loot tables with items not obtainable elsewhere |
| **Environmental Story** | Lore notes and visual storytelling embedded in structure designs |
